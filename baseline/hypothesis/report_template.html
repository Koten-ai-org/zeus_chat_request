Better, worse, and the score

The Versus column compares {{LABEL_B}} with {{LABEL_A}} on the Target API column.

  • better: {{LABEL_B}} called the target API and {{LABEL_A}} did not.
  • worse: {{LABEL_A}} called the target API and {{LABEL_B}} did not.
  • both hit: both packs met the target.
  • both missed: neither pack met the target.
  • not run: a model call is missing.
  • Orange: a pack cell ends on HTTP 400 or higher. Orange stays out of better and worse.
